# スカイルーインズ / Skyruins

スキルツリーで能力を強化しながら進む、Canvas 2D のアクションゲーム。
既存の `../skyruins.html` を変更せず、内容をそのまま `index.html` にコピーして開発を開始しています。

## 起動

Python 3 がある環境では、リポジトリのディレクトリで次を実行します。

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8080/ を開きます。ビルドや npm パッケージのインストールは不要です。

## 操作

- 左右キー: 移動
- Space: ジャンプ
- Z: 射撃 / スキル取得
- P: ポーズ
- M: 音の切り替え
- スキルツリー: 矢印キーで選択、Enter で出発
- タッチ端末: 画面内の操作ボタン

## 構成と依存

- `index.html`: UI、ゲームロジック、描画、音声を含む単一ファイル
- `AGENTS.md`: このリポジトリでの開発ルール
- セーブデータ: ブラウザの localStorage (`skyruins-v1`)
- Google Fonts: DotGothic16 / Zen Kaku Gothic New / M PLUS 1 Code をオンラインで読み込みます。

セーブデータはブラウザとオリジンごとに保存されます。元ファイルとローカルサーバーでは保存先が異なる場合があります。
