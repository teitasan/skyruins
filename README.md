# スカイルーインズ / Skyruins

Three.js の3D横スクロールアクションです。キャラクターは横方向の平面を移動し、カメラは自動追従します。
十字キーとジャンプ・攻撃の2ボタンで遊べることを前提にしています。

## 開発

Node.js 22.13 以上 / pnpm 11.19.0 を使用します。

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:5183/ を開きます。WebGL 2 対応ブラウザが必要です。

```sh
pnpm test
pnpm build
pnpm preview
```

本番配信対象は `dist/` です。`index.html` の直接起動や、ソースをPythonのHTTPサーバーだけで配信する方法は新しい版に対応しません。

## 操作

| 操作 | キーボード | 標準ゲームパッド |
| --- | --- | --- |
| 移動 | ← / → | 十字キー / 左スティック |
| ジャンプ | Space | A (標準マッピングのボタン0) |
| 攻撃 | Z | B (ボタン1) |
| ポーズ | P | Start |
| スキル選択 | 矢印キー | 十字キー |
| スキル取得 | Z / Space | A |
| 次のステージへ | Enter | B / Start |
| 音切り替え | M | — |

タッチ端末では画面の左右ボタンと A / B を使います。カメラ操作や照準操作は不要です。
ジャンプはボタンを押す長さで高さが変わります。
基本移動は加速を伴う歩行速度に調整し、脚の再生速度を実際の移動速度に合わせています。
ジャンプは約3マスの高さを保ちながら上昇を穏やかにし、落下には強めの重力と着地モーションを使っています。

## ゲームの構成

- `src/game.js`: 元の2D版から再利用した、60fpsの物理・敵・戦闘・進行・スキル・セーブ処理
- `src/view.js`: Three.js の地形・背景・キャラクター・アニメーション・演出・自動追従カメラ
- `src/main.js`: 素材ロードとゲーム起動
- `src/style.css` / `index.html`: HUDとメニュー
- `public/assets`: ローカル収録したCC0のモデル・テクスチャ・ライセンス・SHA-256一覧
- `legacy/index.html`: 移行前の2D版をそのまま保存
- `tests/game.test.js`: 移動、ジャンプ、射撃、購入、進行、セーブ、ポーズ、ゲームパッド入力の検証

セーブは従来と同じ localStorage キー `skyruins-v1` を使用し、ステージ・コイン・取得済みスキルの形式を維持しています。
保存先はブラウザとオリジンごとに異なるため、Pages と localhost のセーブは共有されません。
2WAY は画像の意図に合わせ、通常弾1発から上下2発に変化する挙動に整理しています。

この段階の見た目は CC0 のローポリゴン素材で構成した開発用の土台です。
参照画像の精細な石材・草木・キャラクター表現の再現は、今後のアート調整の対象です。
ゲームパッドは標準マッピングで実装・入力テスト済みですが、実機コントローラーと物理モバイル端末は未検証です。
